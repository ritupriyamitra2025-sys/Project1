# 14.ProjectMaking — READ THIS FIRST (any AI, any session)

**Purpose of this folder:** the history and memory of how this project was planned and built.
If a chat is lost, start a new session and read this folder first.

## What is inside

| File | What it is |
|---|---|
| `01-Original-Instructions/` | The owner's original instructions, never edited. `.docx` original + same-name `.txt` for quick reading. New raw instructions (files, chat text, audio transcripts) are added here with a date and number. |
| `02-Project-Understanding.md` (+ `.docx`) | The AI's professional restatement of the project: end goal, workflow, folder map, rules, safeguards. Updated when the owner changes the plan. |
| `03-Instruction-Log.md` | Date-wise log, numbered: **U-n** = owner's instruction, **A-n** = AI's understanding / action. Newest at the bottom. |

## Rules for this folder
1. Never edit or delete files in `01-Original-Instructions/`. Only add new ones.
2. Every new instruction from the owner → add a **U-n** entry in `03-Instruction-Log.md` (date, short summary, link to raw file if any).
3. Every AI decision or action → add an **A-n** entry.
4. If the plan changes → update `02-Project-Understanding.md` and note the change in the log.
5. Use **relative paths only** (for example `../6.Rules/`). The project folder may move from `F:\` to `C:\` or `D:\`.
6. Every `.docx` / `.pdf` has a `.txt` file with the same name next to it.
